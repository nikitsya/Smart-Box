# IoT Development Parts List

| Part | Purpose / Notes | Link | Cost |
|---|---|---|---|
| Raspberry Pi | Main controller. Collects sensor data and sends it to the app. | Use existing Raspberry Pi if available | — |
| Reed switch + magnet | Detects when the paramedic bag is opened or closed. | https://thepihut.com/products/magnetic-contact-switch-door-sensor | £3.40 |
| DHT22 temperature & humidity sensor | Monitors temperature and humidity inside the bag. | https://thepihut.com/collections/the-pi-hut/products/dht22-temperature-humidity-sensor-extras | £8.70 |
| Multi-GNSS Module | Provides location coordinates for the bag. | Supplier/model to be confirmed before purchase | £12.50 |
| Full-size breadboard | Used to build and test the circuit without soldering. | https://thepihut.com/products/full-sized-breadboard | £5 |
| Jumper wires | Connect sensors and breadboard to Raspberry Pi. Male/Male and Female/Male are the most useful. | See lecturer parts list / The Pi Hut | ≈ €4–8 |
| Resistor(s) | May be needed for the DHT22 data line. A 4.7–10 kΩ pull-up resistor is typical. | May already be included with the DHT22 | €0–6 |
| microSD card | Stores Raspberry Pi OS and project software. | Any compatible microSD card, e.g. 32 GB | — |
| Power supply / power bank | Powers the Raspberry Pi and sensors. Exact option depends on the Raspberry Pi model. | To be selected after Raspberry Pi model is confirmed | — |
| Paramedic bag / equipment case | Physical case for the prototype and sensor installation. | Can use an existing suitable bag/case | — |
